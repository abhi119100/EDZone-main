# EDZone – Education Platform

EDZone is a full-stack web application designed to support online education with modern, scalable architecture. It features a React-based frontend and a Node.js backend.

## 📁 Project Structure

EDZone-main/ ├── client/ # ReactJS frontend └── server/ # Node.js backend with REST API


## 🚀 Tech Stack

- **Frontend:** ReactJS, TailwindCSS
- **Backend:** Node.js, Express
- **Database:** (Add info if using MongoDB, MySQL, etc.)
- **Others:** Git, REST APIs

## 💻 Getting Started

### Prerequisites

- Node.js (v14+ recommended)
- npm or yarn
- Git

### Setup Instructions

#### 1. Clone the Repository

```bash
git clone https://github.com/your-username/EDZone.git
cd EDZone

2. Install Dependencies
# For frontend
cd client
npm install

# For backend
cd ../server
npm install

3. Start the App
# In one terminal - start backend
cd server
npm start

# In another terminal - start frontend
cd client
npm start
